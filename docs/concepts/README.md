# Концептуальные изображения MacVitals

Эти SVG-изображения созданы как эстетичные продуктовые визуалы для README. Они намеренно не являются буквальными скриншотами текущей сборки приложения.

- `status-bar-overview.svg` — строка меню и быстрый обзор;
- `preferences-general.svg` — основные настройки;
- `preferences-menu-bar.svg` — настройка строки меню;
- `preferences-fans.svg` — мониторинг вентиляторов и безопасность;
- `preferences-diagnostics.svg` — диагностика системы.

Реальные XCTest-снимки и воспроизводимый сценарий их получения сохранены отдельно в `docs/screenshots/` и `.github/workflows/readme-screenshots.yml` как техническое подтверждение интерфейса. Концептуальные изображения не используются как доказательство реализованных функций.
