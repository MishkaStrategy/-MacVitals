# Performance

## Verification status

No real Mac performance measurements are recorded yet because the current implementation environment is Linux and has no Xcode or macOS hardware sensors. Values are intentionally not fabricated.

The macOS runner must record: device, macOS version, power mode, sampling interval, duration, average/peak CPU, resident memory, thread count, wakeups and limitations. The target profile is a MacBook Pro M1 Pro at a 2-second interval, with no continuous subprocess, disk writes or network activity.
