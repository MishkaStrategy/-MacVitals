# Troubleshooting

- **GPU percentage unavailable:** expected when macOS offers no selected reliable public provider.
- **CPU shows a dash after wake:** the first sample establishes a new counter baseline.
- **Adapter power differs from consumption:** the displayed adapter value is rated/negotiated power, not measured live input.
- **Power sufficiency is unknown:** the evaluator needs enough aligned battery power samples while external power is connected.
- **Unsigned build warning:** build locally from source or explicitly approve the downloaded artifact in macOS settings.
