# Снимки интерфейса MacVitals

Изображения в этой папке получены автоматически из настоящего приложения MacVitals на GitHub-hosted runner с macOS 15 ARM64.

- `status-bar-overview.png` — реальный status item в строке меню macOS и раскрытый обзор показателей, 900×820;
- `preferences-general.png` — основные настройки на русском языке;
- `preferences-menu-bar.png` — настройка показателей строки меню;
- `preferences-fans.png` — мониторинг вентиляторов и ограничения безопасности;
- `preferences-diagnostics.png` — диагностика источников данных.

Это XCTest-снимки запущенного приложения, а не макеты или концепт-рендеры. Воспроизводимый сценарий находится в [workflow README Screenshots](../../.github/workflows/readme-screenshots.yml).
